# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, be kind, assume good intent, and focus feedback on the work rather than the person.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any
other project space.

## Reporting

Report unacceptable behavior privately through
[GitHub's private reporting](https://github.com/john1hsu/salesforce-quiz-api/security/advisories/new) or by
contacting the maintainer via their GitHub profile. Reports are handled confidentially, and maintainers may
remove content or block contributors who violate this code, as described in the Covenant's enforcement
guidelines.
